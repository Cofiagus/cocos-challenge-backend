POST /api/users/:userId/orders — una sola transacciónsrc/application/orders/submit-order.ts
  1. withUserTransaction abre tx + advisory lock por usuario.
  2. userExists → 404  ·  instrumento por id|ticker → 404 / MONEDA → 400 (sin orden).
  3. precio de referencia (última vela) → sin precio = REJECTED NO_PRICE persistida.
  4. size explícito o floor(amount / precio) → 0 = REJECTED ZERO_SIZE.
  5. fondos/tenencia leídos dentro de la tx → REJECTED INSUFFICIENT_*.
  6. createOrder = primera escritura (claim idempotente); replay → orden original, conflicto → 409.
  7. appendOrderEvent en la misma tx → 201 con la orden persistida (también si quedó REJECTED).
